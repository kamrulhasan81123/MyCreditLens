# OpenDOSM — Malaysian household income (localisation context)

- **Dataset name:** Household Income by State (`hh_income_state`)
- **Original URL:** https://api.data.gov.my/data-catalogue?id=hh_income_state
  (catalogue: https://open.dosm.gov.my/data-catalogue)
- **Publisher:** Department of Statistics Malaysia (DOSM) / data.gov.my
- **Download date:** 2026-08-12
- **Licence:** data.gov.my open data terms (Malaysian Government open data)
- **Geography:** Malaysia (state level)
- **Date range:** 1970–2024 (Household Income & Expenditure Survey, HIES)
- **Records:** 319 (state × survey year). Fields: `date`, `state`, `income_mean`,
  `income_median` (nominal RM, not inflation-adjusted).

## Role — context ONLY

> **OpenDOSM provides Malaysian socioeconomic context but does NOT provide
> borrower-level repayment outcomes.**

Permitted uses: RM income-range sanity checks for synthetic/borrower simulation,
state-level segmentation, dashboard context, and research discussion. It is
**never** used as a default label and does not validate default prediction.
Additional OpenDOSM catalogues (district/parliament income, expenditure) are
available from the same API if needed.
